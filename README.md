 # Superstore Sales Dashboard

## Project Overview
Created an interactive Power BI dashboard using Superstore sales data to analyze sales performance, profit trends, customer segments, and regional insights.

## Tools Used
- Power BI
- DAX
- Data Visualization
- KPI Analysis

## Key Insights
- Technology category generated strong sales
- Standard Class was the most used shipping mode
- West region showed strong sales performance
- Phones and Chairs were top-performing sub-categories

## Dashboard Features
- Interactive filters
- KPI cards
- Regional sales analysis
- Category-wise performance tracking
- Profit trend visualization
